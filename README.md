# Sound Wave Generator

**Интерактивный генератор звуковых волн с визуализацией и горячими клавишами.**

Проект позволяет генерировать звуковые волны разных типов (синусоида, квадратная, треугольная) с визуализацией в реальном времени. Поддерживаются:
- Режим "только звук" (отключение визуализации для экономии ресурсов).
- Горячие клавиши для быстрого изменения параметров.
- Локализация интерфейса (английский и русский).
- Переключение между светлой и тёмной темами.

---

## Описание
Sound Wave Generator — это веб-приложение для создания и прослушивания звуковых волн в реальном времени. Приложение поддерживает три типа волн:
- Синусоидальная волна.
- Квадратная волна.
- Треугольная волна.

Приложение оптимизировано для работы на слабых устройствах и включает:
- Адаптивный интерфейс для всех устройств.
- Плавные анимации визуализации.
- Сохранение настроек в localStorage.
- Использование Web Workers для повышения производительности.

## Установка и использование
1. **Загрузите проект** через GitHub или откройте файл `index.html` напрямую в браузере.
2. **Требуется:** Современные браузеры (Chrome, Firefox, Safari, Edge) с поддержкой Web Audio API.
3. **Запуск:** Откройте `index.html` и начните экспериментировать с параметрами.

Для интеграции в ваш проект скопируйте файлы:
- `index.html`
- `script.js`
- `sound.js`
- `styles.css`
- `worker.js`

## Функционал

### Горячие клавиши
| Клавиша       | Действие                          |
|----------------|-----------------------------------|
| ↑ / ↓          | Изменение частоты звука           |
| Ctrl + ↑ / ↓  | Изменение амплитуды звука         |
| 1 / 2 / 3      | Переключение типа волны           |
| Esc            | Сброс настроек                   |

### Режимы работы
- **Визуализация волны:** Показывает график звука в реальном времени.
- **Только звук:** Отключает визуализацию для экономии ресурсов на слабых устройствах.

### Настройки
- **Сохранение настроек:** Все параметры сохраняются в localStorage для быстрого восстановления.
- **Переключение тем:** Используйте переключатель в настройках для активации светлой или тёмной темы.

### Локализация
- Поддерживаются языки: Английский и Русский.

## Примеры кода
Для интеграции в ваш проект используйте следующий пример:

```html
<!-- Включите файлы в ваш HTML -->
<script src="script.js"></script>
<link rel="stylesheet" href="styles.css">

<!-- Инициализация генератора волн -->
<canvas id="waveCanvas"></canvas>
<div id="controls"></div>
<script>
  const generator = new SoundWaveGenerator(document.getElementById('waveCanvas'), document.getElementById('controls'));
  generator.init();
</script>
```

## Тестирование на слабых устройствах
Для проверки производительности на слабых устройствах (процессор 1.5 ГГц, 2 ГБ ОЗУ) рекомендуется:
1. Отключить визуализацию волны в настройках.
2. Использовать эмуляторы браузера для тестирования.
3. Наблюдать за плавностью работы и отсутствием лагов.

Результаты тестирования доступны в [отчёте](test_performance_real_device.js).
